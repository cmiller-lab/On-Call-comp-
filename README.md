# On-Call Payroll PWA

A small installable web app for assigning weekly on-call coverage and generating a payroll-ready text summary.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of the `dist` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public URL after deployment. Open that URL in Safari on iPhone or iPad and choose **Share → Add to Home Screen**.

## Pay rules included

- Full covered week: $850.00 exactly
- Monday–Friday: $106.25 per day
- Saturday/Sunday: $159.38 per day
- Holiday add-on: $175.00
- Automatic holidays: New Year's Day, Memorial Day, Independence Day, Labor Day, Thanksgiving, day after Thanksgiving, and Christmas

All rates and technician names can be changed from the settings button. Assignments and saved reports are stored only on the current device.
